# Cloud Support Project 01 – Amazon ECS Production Troubleshooting

This project demonstrates production-style troubleshooting of applications running on **Amazon ECS (Fargate)**. Each lab simulates a real-world incident, identifies the root cause, and restores the service.

## AWS Services

- Amazon ECS (Fargate)
- Application Load Balancer (ALB)
- Amazon ECR
- AWS IAM
- Amazon CloudWatch
- Amazon VPC

## Troubleshooting Labs

A.  Lab 01 – ALB Health Check Misconfiguration
B.  Lab 02 – ECS Container Port Mapping Error
C.  Lab 03 – Container Startup Failure (Invalid Nginx Configuration)
D.  Lab 04 – ECS Image Pull Failure from Amazon ECR
E.  Lab 05 – IAM Execution Role Misconfiguration

## Skills Demonstrated

- ECS Deployment Troubleshooting
- Root Cause Analysis
- CloudWatch Log Analysis
- IAM Permission Debugging
- Docker & Amazon ECR
- ALB Health Check Diagnostics
- Production Incident Recovery

## Key Outcomes

- Diagnosed and resolved multiple production-style ECS failures
- Investigated issues across networking, IAM, containers, and image deployment
- Used CloudWatch logs and ECS service events for root cause analysis
- Successfully restored services after each simulated incident


> Each lab includes the scenario, investigation, resolution, and supporting screenshots.
