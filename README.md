# LMS – AWS Container Deployment & Troubleshooting

A hands-on AWS project demonstrating **containerized application deployment and Cloud Support troubleshooting using Amazon ECS**.

## Architecture

**Docker -> Amazon ECR -> Amazon ECS Fargate -> Application Load Balancer -> User**

## AWS Services

* Amazon ECS Fargate
* Amazon ECR
* Application Load Balancer
* Amazon VPC
* Security Groups
* IAM

## What I Implemented

* Containerized the LMS application using Docker
* Built and pushed the container image to Amazon ECR
* Deployed the application using Amazon ECS Fargate
* Configured networking and security groups
* Connected the application through an Application Load Balancer
* Performed application health validation
* Investigated and resolved a container/application health issue

## Deployment & Troubleshooting Flow

**Build Container -> Push to ECR -> Deploy to ECS -> Configure Networking -> Validate Application -> Investigate Failure -> Restore Service**

## Cloud Support Skills Demonstrated

**AWS, ECS, Docker, ECR, Networking, Security Groups, Load Balancing, Container Troubleshooting, Health Checks, Incident Investigation, Root-Cause Analysis, Recovery Validation**

## Project Outcome

Successfully deployed a containerized LMS application on AWS and demonstrated the ability to **troubleshoot a production-style application issue, identify the failing layer, apply a fix, and validate service recovery.**
