
# Cloud-Support-Lab

Hands-on AWS troubleshooting projects built in a self-managed Free Tier environment, documented as support tickets: problem, diagnosis, root cause, fix.

## Projects

### 1. ECS Container Troubleshooting — LMS Migration
Containerized app deployment and debugging on ECS Fargate. Services: ECS Fargate, ALB, Target Groups, CloudWatch Logs, ECR, Security Groups
Covers: task health checks, container port misconfiguration, load balancer routing, security group rules, log-based root cause analysis.
