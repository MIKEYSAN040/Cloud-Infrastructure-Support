# 🚀 Project 01 - Troubleshooting a Containerized LMS on Amazon ECS

## 📌 Project Overview

This project simulates a real-world Cloud Support Engineer scenario where a Learning Management System (LMS) application is migrated to Amazon ECS using AWS Fargate.

The application is intentionally deployed with multiple misconfigurations to practice troubleshooting production issues.

The objective is not just to deploy the application but to identify, investigate, and resolve infrastructure and application failures using AWS services.

---

# 🎯 Objectives

- Learn Amazon ECS
- Deploy containers using AWS Fargate
- Configure an Application Load Balancer (ALB)
- Debug ECS deployment failures
- Analyze CloudWatch Logs
- Troubleshoot networking issues
- Fix Security Group misconfigurations
- Understand production incident workflows
